# International Syriac Medical Association — ISMA

Prepared for the organization GitHub Pages site: https://isma-org.github.io

Repository name: `isma-org.github.io`

Languages:
- English: `/`
- Deutsch: `/de/`
- العربية: `/ar/`
- ܣܘܪܝܝܐ: `/sy/`

News and publications are maintained through JSON files in `content/{language}/news.json` and `content/{language}/publications.json`.

Publishing:
1. Create or rename the organization repository to `isma-org.github.io`.
2. Upload the contents of this package to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Open `https://isma-org.github.io` after GitHub Pages finishes deploying.

Keep the previous `ISMA` repository until the new site has been tested.
